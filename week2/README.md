# Week 2: AI Engineering Fundamentals

Welcome to the Week 2 repository for the AI Engineering project. This week focuses on core concepts in prompt engineering, agentic workflows, and modular prompt design.

## Overview
This week's curriculum covers the progression from basic prompt engineering techniques to more complex, iterative agentic patterns and chained workflows.

## Daily Breakdown

### [Day 1: Prompt Engineering](./day1/)
*   **Focus:** Core principles of effective prompt engineering.
*   **Key File:** `prompt_engg.py`
*   **Concepts Covered:** Structuring prompts for clarity, context setting, and improving model response quality.

### [Day 2: ReAct Looping](./day2/)
*   **Focus:** Implementing the ReAct (Reasoning and Acting) framework.
*   **Key File:** `react_looping.py`
*   **Concepts Covered:** Creating iterative loops where the model reasons about a task, performs an action, observes the result, and adjusts its strategy accordingly.

### [Day 3: Prompt Chaining](./day3/)
*   **Focus:** Breaking down complex tasks into sequential, manageable steps.
*   **Key File:** `promptChaining.py`
*   **Concepts Covered:** Passing outputs from one LLM call as inputs for the next, enabling more sophisticated and reliable problem-solving.
